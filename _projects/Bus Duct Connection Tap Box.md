# Bus duct connection box

<p class="project-kicker">Power Bus Way · generalized professional example</p>

## Design problem

A connection box has to join existing bus duct to a cable-bus run while keeping the conductor route and bolted connections accessible.

## My role

I check the flange fit, conductor path, and access to the bolted connections.

**Design decision:** I use the existing flange as the interface reference, then review the conductor route and enclosure space around it.

**Constraints:** the existing interface and nearby equipment limit the arrangement. Customer dimensions, ratings, and production drawings are not shown.

**Outcome:** I support model and drawing updates and help resolve fit questions for assembly and installation. The diagram is a general concept, not a customer drawing.
